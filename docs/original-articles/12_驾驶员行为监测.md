# 基于 Jetson Orin Nano 与 MediaPipe 的驾驶员行为监测

> 来源: 微信公众号 https://mp.weixin.qq.com/s/A8cpp4IKpJjFNURR1O5NuA (web_fetch抓取版)

## 项目概述

基于 Jetson Orin Nano 与 MediaPipe 的驾驶员行为监测系统。属于NVIDIA Jetson 2026征文赛道的边缘视觉检测/通用视觉Agent类项目。

## 技术栈

- 硬件：Jetson Orin Nano（8GB）
- 视觉：MediaPipe（手部/姿态估计）+ YOLO
- 推理：TensorRT + CUDA 加速
- 系统：JetPack + OpenCV

## 功能

- 驾驶员疲劳/分心行为监测
- 姿态关键点检测（MediaPipe Pose）
- 实时告警

## 逆向分析要点

| 维度 | 提取 |
|------|------|
| 核心链路 | 摄像头→MediaPipe姿态→行为分类→告警 |
| 关键模型 | MediaPipe Pose + YOLO |
| 可复用 | MediaPipe在Jetson上的TensorRT部署方式 |
