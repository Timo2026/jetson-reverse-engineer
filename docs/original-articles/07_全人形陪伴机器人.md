# Jetson Orin NX 与全人形陪伴情感机器人的控制制作

> 来源: CSDN https://blog.csdn.net/ShuaiRu/article/details/162573541 (web_fetch抓取版)

## 1. 项目场景与开发背景

解决仿生脸 + 灵巧手 + 全身机器人控制的工程化实现。2026年2月接手宇树G1机器人全身控制项目（第六代目，前五代全部卡死）。最终实现可对话的AI全人形机器人。

## 2. 全套技术栈

- Jetson设备：宇树G1自带 Jetson Orin NX，JetPack 6.2，CUDA 12.1，TensorRT 10.7，ROS Humble
- 控制：NVIDIA官方 GearSonic（GR00T-WholeBodyControl）进行全人形控制
- 音频：宇树官方音频SDK
- 仿生头：内部自研基于音素的控制方案
- 灵巧手：舞肌SDK（五指的舞肌灵巧手）
- 遥操：Pico VR方案（Pico4 Pro，反编译降SDK版本适配）

## 3. 全流程开发

1. MP4 → GVHMR → GMR → 机器人动作（视频驱动动作）
2. 动作编辑软件
3. 数据采集系统
4. 仿生头接入（AI对话）
5. Pico VR遥操
6. 舞肌灵巧手接入（10A电流，需缓速过度代码防断电）

## 4. 难点排查

- 环境地狱：JetPack 5.1.1缺leg_control库 → 6.0缺onnxruntime-gpu → 6.2才是GearSonic要求
- RTC问题导致无网（时间回到1980）
- 手一断连身体控制也退出 → 代码隔离运行+热重连
- 供电：12V不够用50V降压，两块电源板并联
- 转接头自建模制作

## 5. 效果量化

- 控制频率30Hz，AI对话延迟2-3秒
- 豆包TTS，通用问题准确率可接受
- 成本：手10万+宇树G1 20万+头10万
- 恐怖谷效应（机械人形 vs 优必选硅胶仿真）

## 6. 逆向分析要点

| 维度 | 提取 |
|------|------|
| 核心链路 | 视频→GVHMR→GMR→机器人动作 |
| 控制架构 | GearSonic (GR00T) + ROS Humble |
| 关键教训 | 硬件供电冗余、模块隔离、热重连 |
| 可复用 | 音素驱动仿生脸、舞肌手控制、Pico遥操 |
