# 在 Jetson Orin 上，我把「能打断的」语音助手跑通了

## 项目概述

在 Jetson Orin 上实现的**可打断（barge-in）语音助手**——用户说话时可以打断助手播报，实现自然对话体验。属于离线多模态/语音交互赛道。

## 预期技术栈（基于领域知识）

- 硬件：Jetson Orin（8GB/16GB）
- STT：本地语音识别（如 Whisper / Vosk / sherpa-onnx）
- TTS：本地合成（如 Piper / edge-tts）
- 打断检测：VAD（Voice Activity Detection）+ 双工流式设计
- LLM：Ollama 本地大模型（Qwen等）

## 核心难点（可打断）

1. **双工架构**：播放TTS同时监听麦克风
2. **VAD灵敏调优**：区分环境噪声与用户打断
3. **流式STT**：边录边识别降低响应延迟
4. **低延迟链路**：STT→LLM→TTS全本地，目标<1s

## 逆向分析要点

| 维度 | 提取 |
|------|------|
| 核心链路 | 麦克风→VAD→STT→LLM→TTS→播放 (可打断) |
| 关键设计 | 双工音频流 + 打断检测 |
| 可复用 | 本地语音助手架构（对OpenClaw语音扩展有价值） |
