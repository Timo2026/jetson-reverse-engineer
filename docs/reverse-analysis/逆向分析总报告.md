## 01_BEVFusion_jetson_agx. 基于Jetson AGX实现BEVFusion（自动驾驶多传感器融合）

- **赛道**: 自动驾驶/车载感知
- **硬件**: Jetson AGX (Orin/Thor级)
- **技术栈**: TensorRT + CUDA + FP16/INT8 + TRT Engine

### 架构逆向
```
BEVFusion = 相机分支 + LiDAR分支 → BEV空间融合 → TransFusion → BBox Head
- Camera Backbone: 6×3×256×704 → camera_feature + depth_weights (静态shape优化)
- Camera VTransform: 80×360×360 → 80×180×180
- TransFusion: camera(80×180×180) + lidar(256×180×180) → middle(512×180×180)
- BBox Head: middle → score/rot/dim/reg/height/vel (6输出, 200 proposals)
- 性能: 总延迟191.8ms→63-78ms (FP16优化后), 单帧33个检测目标
```

### 核心洞察
- 静态Shape模型是Jetson部署关键（动态shape拖慢kernel选择）
- FP16精度足够，INT8需仔细校准
- Camera Bevpool 12.9ms + Lidar Backbone 32.5ms 是大头
- 推理管线按模块拆分计时，方便定位瓶颈

### 可复用组件
- BEV特征融合模式、静态shape导出、模块化计时评测框架

### 本机(CPU)可运行demo方案
- CPU模拟BEVFusion数据流：合成相机+Lidar特征→BEV网格融合→目标框输出，展示融合原理

## 04_OrinNX_工业缺陷检测. 基于Jetson Orin NX的轻量化工业缺陷检测系统

- **赛道**: 工业/巡检机器人
- **硬件**: Jetson Orin NX 16GB + 海康GigE相机 + 奥比中光结构光
- **技术栈**: JetPack 6.0 + CUDA 12.2 + TensorRT 8.6 + OpenCV CUDA + VPI + Docker + Triton

### 架构逆向
```
YOLOv8m-seg实例分割 (INT8量化)
GigE相机→RingBuffer(32帧)→预处理线程池(OpenCV CUDA)→TensorRT INT8引擎→后处理(掩膜面积/长度/CAD公差比对)→GPIO气吹剔除
- INT8量化: 50.2MB→14.8MB, 35ms→22ms, mAP 93.7%→92.9%
- 混合精度: backbone INT8 + neck/head FP16 (细微划痕检出率71%→89%)
- 深度融合: 结构光凹陷特征匹配提升置信度20%
```

### 核心洞察
- 全INT8并非最优，关键层保留FP16
- 单引擎+多Stream优于多引擎多线程（显存1.5GB内）
- Producer-Consumer解耦防丢帧
- GPIO连续3帧一致判定滤波防误触发

### 可复用组件
- TensorRT INT8混合精度方案、RingBuffer管线、缺陷仲裁逻辑

### 本机(CPU)可运行demo方案
- CPU模拟：合成缺陷图像→(模拟TensorRT)→缺陷分类+掩膜面积→OK/NG判定→GPIO信号

## 05_PanoTwin_高斯泼溅. PanoTwin：Jetson Orin NX + 影石X5 边缘端高斯泼溅数字孪生

- **赛道**: 工业/巡检机器人(数字孪生)
- **硬件**: Jetson Orin NX 16GB (reComputer J4012) + Insta360 X5
- **技术栈**: JetPack 6.2 + CUDA 12.6 + TensorRT 10.3 + DAP(CVPR26) + D²GS(ICLR26) + COLMAP + gsplat + Gemma E4B

### 架构逆向
```
三级流水线:
1. 标定: Kalibr + CO-Calib选帧器(200行Python, s_iso/s_drs判据) → 180°背靠背鱼眼标定
2. 深度: DAP全景度量深度(DINOv3-Large骨干, TensorRT FP16, 深度头FP32) → 512×1024等距柱状
3. 重建: D²GS稀疏视角3DGS (DD-Drop + DAFE) → 高斯泼溅.ply/.splat + 占据栅格
语义层: Ollama + Gemma E4B 空间问答
```

### 核心洞察
- 16GB统一内存是选型门槛（不是算力）
- FP16而非INT8：深度回归尺度漂移致命
- stop-and-shoot采集：16张清晰图>2000张糊图
- .insv改.mp4即可解封装（无aarch64官方SDK绕过）
- CO-Calib: 径向跨度>图像均匀覆盖（标定板沿径向扫）

### 可复用组件
- CO-Calib选帧器实现、DAP深度先验+3DGS耦合、全离线流水线

### 本机(CPU)可运行demo方案
